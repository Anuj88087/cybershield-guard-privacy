Privacy Policy for CyberShield Guard

Last Updated: November 23, 2026

Developer: Anuj Srivastava

1. Overview

CyberShield Guard is designed to help users detect suspicious links (such as lookalike domains, punycode xn-- domains, and risky URLs), risky APK/XAPK sideload packages, and potential phishing indicators with a local-first approach.

2. Permissions & How They Are Used

  • Accessibility Service: Used strictly to inspect visible URLs/links and text context in supported apps and browsers in real time so the app can warn users about potentially suspicious links or phishing patterns. It does not change device settings without user intent or collect personal messages for advertising.
  • System Overlay Alerts: Used only to display timely warning popups when a suspicious link or file is detected.
  • Storage / File & App Audit Access: Used to inspect downloaded/shared files (such as APKs) and audit installed apps/permissions on the device for potential security risks.

3. Local Storage & Data Handling

Threat history logs, trusted domains (allowlist), snooze preferences, and security health evaluations are stored locally on the user's device. We do not sell or rent user data to third parties.

4. User Controls

Users can manage trusted domains, use 1-hour snooze, clear threat history, or revoke permissions anytime from Android Settings.
