# CyberShield Guard

An Android security and mobile threat defense application built with Kotlin, focused on detecting suspicious links, lookalike/punycode domains, risky APK/XAPK sideloads, and phishing indicators using a local-first approach.

## Key Features & Architecture
- **Real-Time Link & Text Inspection (Accessibility Service):** Monitors visible URLs/links and text context in supported apps and browsers to warn against suspicious links or phishing patterns.
- **Timely Alert Overlays (System Overlay):** Displays warning popups when a potentially risky link or file is detected.
- **File & App Audit:** Inspects downloaded/shared files (such as APKs) and audits installed apps/permissions for potential security risks.
- **Local-First Storage:** Stores threat history logs, trusted domains (allowlist), snooze preferences, and security health evaluations locally on the device without selling or renting user data to third parties.
